# MOR TERMINAL

Terminal de inteligencia financiera: contratos de defensa de EE.UU. + small caps globales
de defensa + mercados de predicción (Polymarket) + noticias por región.

## Uso inmediato
Abre `index.html` con doble clic. No necesita servidor ni instalación.

## Publicar en internet (gratis)
Ver `docs/DESPLIEGUE.md`. Resumen: pegar `worker.js` en un Worker de Cloudflare.

## Atajos
- `F1`–`F5` cambian de vista
- `/` salta al buscador
- Comandos: `CON`, `SC`, `PM`, `NEWS`, `DASH`, `REFRESH`

## Fuentes
USAspending · Polymarket · war.gov · Google News. Todas públicas y gratuitas.

*Informativo. No es recomendación de inversión.*
